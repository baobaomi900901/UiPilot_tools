# macOS Runtime 请求通道的共享生命周期核心

本单元承接[原样 ESM 实验](2026-11-08-macos-quickjs-runtime-probe-design.md)，将请求归属与撤销规则实现为产品目录中的共享 Rust 核心，并由独立 QuickJS 子进程夹具验证。它不装配生产 Mac 插件服务，也不改变公开 SDK 的线协议、权限或 Windows Runtime 行为。

## 同源合同与权限边界

最小提取现有插件 ID 校验器和请求/调用 DTO，原模块保留导出路径。字段、serde 属性、请求 ID 形状和 invocation 的旧式 commandId 省略规则保持不变。Windows 与 Mac 编译同一份核心；独立实验也引用真实源码，不复制验证器、不伪造 scheduler owner 或 Windows caller label 来绕过依赖。

共享 `data_call_gate` 继续负责 plugin/generation/activation/admission 的准入与排空。新的 session 核心补充单次请求、宿主实例、截止时间和调用完成归属。它不替代具体服务的 manifest、授权、参数及结果验证。测试内存服务必须明确命名为夹具，不注册为真实 settings/storage/secret/network API，也不能将其成功计入 SDK 可用能力。

## 请求、调用与回复

宿主创建实例 token 并绑定请求，持有不可序列化的对象身份；传输适配器保留它。子进程提供的 ID 只是消息一致性检查，不能据此构造或选择权限。旧 endpoint 即使带上新请求的文本字段，也不能操作新请求。相同文本身份重新创建的实例仍须区分；PID 不构成授权身份。

每次调用检查当前实例、完整请求上下文、单调时钟截止时间和真实 data gate，成功才取得操作许可。调用 ID 有界且不可重复消费；调用与回复均计入在途数，重复或迟到的结果不能再次提交。回复准入也须复验 gate，不能因为最初服务调用获准就无限期保留发送权。

完成分为准备和最终提交。准备须在同一生命周期锁内确认没有未完成的调用或回复，并关闭后续准入；生成的完成许可只属于原请求且只能消费一次。适配器再核对自己的终结条件，最终提交重新检查当前身份、gate 与 deadline。没有成功退出或其他适配器终结证据时，实验不得发布成功结果。完成许可本身不是 OS 进程退出证明。

最终提交的实际操作在短锁外执行，并由新的 gate lease 和在途计数覆盖。它一旦获准，后续 close/replacement 不能撤回已经发放的许可；排空完成才证明该操作结束。产品 UI 接线仍须在真正发布时核对原 UI owner，或先排空旧操作再开放共用目标，不能把核心准入扩大为任意 UI 回调永不覆盖新结果的保证。

## 撤销、锁序与失败

先关闭准入，再取消传输及未完成操作，最后在锁外排空。close/open 不会撤回已准入的操作闭包，旧 drain 完成才保证其结束；它不能借用新身份发起调用。共用目标须先等 drain，或在 UI 最终发布时核对原 owner，核心不保证 open 返回后零旧 UI 副作用。重新授权产生新身份，旧 drain 只等待旧许可；旧 close 不能撤销新实例。

锁序采用 session → data gate；activation 撤销在 gate.close 返回并释放其锁后才能进入 session.close。不得持有这些锁等待管道读取/写入、进程退出或外部回调，也不能先等待被阻塞的管道操作排空再终止子进程。许可丢弃/错误路径释放在途计数，重复 close 保持关闭，不隐式重新打开。

session 的关闭只证明宿主准入和许可生命周期；对端是否还在执行或能观察此前发送的数据，由适配器单独说明。[后续 XPC 边界](2026-11-08-macos-runtime-xpc-boundary.md)不能用本轮管道 kill/wait 代替。

## 独立进程夹具与验收

`spikes/macos-runtime-bridge-probe/` 使用锁定的 QuickJS 依赖、固定内存模块和有界消息。父进程监督双向通信及 stderr，限制输入、帧大小、累计输出和截止时间；格式错误、超限、重复完成或进程异常一律拒绝。所有失败路径清理并回收实际子进程；不得仅以线程超时返回而遗留执行中的 helper。

共享核心的确定性测试分别覆盖：错误实例/上下文、重复 call/reply、deadline、gate 撤销、旧请求晚于替代请求、完成前仍有在途回复、准备后撤销/过期导致提交失败，以及关闭排空与新身份互不影响。真实子进程另验证一次内存调用往返、撤销时阻塞/迟到回复、重复协议消息、异常退出和正常完成后的回收。只对夹具结果作断言，不调用个人数据、系统权限、GUI 或音频。

主 crate 编译和回归验证共享提取；独立实验保留源码与二进制哈希、实际测试数量和进程终态。Windows 原生运行、生产调度与服务授权接线、包快照和 OS 沙箱分别列为未验。生产插件开关保持关闭，同包双端生产通过数不随本单元增加。
