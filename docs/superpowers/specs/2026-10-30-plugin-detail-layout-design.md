# 插件详情页与启动配置统一

## 用户确认的范围

详情页使用「返回、插件名称、常用星标」页头，内容按启动、版本号、插件说明、权限列表、网络 Host、网络访问权限、插件所在目录、操作区域排列。内置 `/screenshot`、`/quicklinks`、`/web-search` 与公开插件统一支持修改启动指令、恢复默认、录制及清除启动快捷键。

用户已确认：允许多个插件使用同一启动指令；输入同名指令时列出全部匹配项，由用户选择。旧版插件兼容区保持现状。内置功能不可删除。此次不修改 rust_uia。

## 页面与交互

- 页头三部分垂直居中；插件名称可截断，完整名称可查看；星标按钮具有 tooltip、可访问名称及 aria-pressed。
- 单命令插件的星标直接切换该命令的常用状态。多命令插件在启动区域提供命令选择，星标、指令输入框和快捷键配置都作用于所选命令；切换前提交已编辑的指令，提交失败时保留草稿和当前命令。
- 启动区域第一行：指令输入框、初始化按钮。失焦自动保存，Enter 也可提交；值未变化不写入；初始化只恢复该命令的默认指令，不清空快捷键、常用或插件数据。点击初始化时由初始化操作负责此次提交，避免先写入草稿再恢复。
- 输入允许显示完整 `/命令`，保存时统一规范化一个前导 `/` 和首尾空白。非法命令仍拒绝，重复名称不作为错误。空值不删除命令，显示行内错误。
- 启动区域第二行：快捷键输入框、录制、清除。未配置时在框内显示“未设置”。保留原录制生命周期、Escape 取消、系统占用及冲突校验；快捷键本身不允许重复。
- 保存过程和失败采用行内反馈；未确认写入结果时先重新读取状态，不自动重复写入。切换详情后，旧请求不能覆盖新插件或新命令的内容。
- 版本只读；说明按多行文本展示并保留换行。权限逐项显示申报名称与授权/未授权/不支持状态。
- 网络 Host 显示实际申报的 HTTPS 主机。网络相关行仅在申报网络能力时出现；“网络访问权限”使用现有整体授权开关，开启保留主机及凭据绑定确认。此设计不新增逐 Host 授权模型。
- 插件普通设置和凭据设置继续保留在内容区，避免重排页面后失去现有配置入口。
- 插件所在目录显示宿主管理的实际安装目录，长路径可换行、可选择复制。开发目录快照的安装目录与原始开发源码目录不混淆。
- 操作区域：重新载入、删除、查看诊断。重新载入沿用现有开发目录选择、校验与确认流程，仅收紧按钮文案；不会暗中重新启用已关闭插件。
- 删除弹窗提供“保留插件数据”复选框，默认选中，以及取消、删除按钮。只有确认删除才调用卸载；成功后返回插件列表。关闭、取消、Escape 都不卸载。
- 查看诊断后在操作区下方展开只读多行文本域，显示本次诊断快照，可选择和复制。保留现有诊断脱敏与容量边界，不展示密钥，也不将快照称为持续实时日志。
- 内置详情使用同样的页头及启动布局；权限和目录明确标注宿主内置属性，不伪造插件申报权限。隐藏独立插件才具备的卸载、开发目录重载和插件 Runtime 诊断动作。
- 使用现有主题 token，遵循 `docs/ui-guidelines.md`；检查深浅主题、窄窗口、Tab 顺序和弹窗焦点恢复。

## 启动指令与匹配

名称是可编辑的显示及搜索入口，插件 ID + 命令 ID / 内置功能枚举仍是稳定执行标识。重名不能导致 ID、常用、配置或快捷键归属互相覆盖。

公开插件之间、三个受管理内置功能之间、公开插件与这三个内置功能之间允许重名。宿主其他保留指令（例如 `/find`）仍保留，禁止冒充它们。恢复默认也遵循相同规则，允许与其他可配置命令重名。

完整指令有多个可用匹配项时，不自动启动第一个。列表显示插件名称和命令标识，保留输入参数，用户选择后通过稳定标识执行。已停用或故障项不参与可执行匹配；前缀提示、完整匹配、携带参数、常用入口、快捷键入口均保持稳定归属。只有一个可用匹配项时保留既有启动体验。

内置指令覆盖值持久化到宿主设置，旧设置缺少字段时使用当前默认指令。改名后旧别名不继续作为隐藏入口；内部既有固定功能标识仍用于分派，不能把公开插件的同名输入误解释成内置执行。

## 内置快捷键

复用现有宿主全局快捷键注册、录制暂停、系统冲突检测及生命周期机制。截图继续兼容已保存的 screenshot_hotkey，并让通用设置与详情页操作同一份配置。快速链接和网页搜索增加持久化快捷键配置，不复用公开插件 ID 空间。

保存流程必须先校验和准备注册，持久化失败恢复先前注册；注册失败不发布新的已保存状态。与主启动器、截图、其他内置和公开命令快捷键统一检测冲突。关闭内置功能使其快捷键暂停，重新开启后按现有规则恢复；重启后恢复绑定。录制期间不触发功能。

## 数据与权限边界

新增和修改的管理 IPC 沿用仅授权宿主主界面的管理边界；插件 WebView 不能利用该变更读取安装路径或更改宿主快捷键。清单 DTO 补充实际安装路径；内置视图补充默认/有效指令、常用和快捷键状态。更新严格解析器、浏览器预览与测试数据，保持旧持久化设置兼容。

删除沿用 retainData 合同；保留数据包含既有插件数据处理语义，不新增无条件删除目录。网络授权、凭据确认和插件隔离不因布局变化放宽。

## 验收

1. 页头对齐，所有指定字段和操作符合布局；单/多命令插件、三种内置功能、无网络/有网络插件都可操作。
2. 失焦只提交一次；初始化不先提交草稿；失败不丢草稿、不显示虚假成功，旧异步响应不串详情。
3. 同名指令在保存、重载和重启后仍有效；无参数和带参数都列出所有可执行匹配，选择后启动正确插件；保留指令仍受保护。
4. 内置快捷键与主启动器及公开插件冲突被拒绝；保存/注册失败回滚、关闭暂停、录制暂停、重启恢复均有验证。
5. 删除取消不调用卸载；两种数据保留选择传递正确，成功返回列表；内置没有删除入口。
6. 网络授权确认及凭据编辑保留；实际路径可见；诊断按需展开且维持原脱敏边界。
7. 前端类型检查、相关测试和 Rust 定向测试通过；深浅主题及窄窗口检查通过。
