# 内嵌面板统一状态栏

用户要求所有内嵌面板保留宿主底栏，将 Notes 保存成功、失败等操作提示移到底栏。延续当前底栏几何、主题颜色及 aria-live，不发系统通知、不抢焦点。

移除 Panel 模式隐藏底栏的 CSS；子 WebView 继续通过现有 ResizeObserver 接收内容区域尺寸，避免覆盖底栏。左侧显示状态反馈，右侧固定显示通用面板操作提示，不显示残留的搜索结果计数。清除反馈只清空左侧；状态长文本单行省略且可通过悬停 title 查看，不挤占右侧操作提示。设置页操作提示采用同一分区，版本号仍在最右侧。

新增 `uipilotPluginPanel.setStatus({message, tone?})`，tone 为 info/success/error，默认 info，空 message 清除。消息最长 512 Unicode 字符，不支持 HTML。桥接调用绑定获取方法时的 sessionEpoch，并带文档内递增序号；后端验证内容 WebView 身份和会话，事件只发到 main。主程序只接受当前面板会话的新序号，关闭/替换面板丢弃状态。

Notes 全部短期操作反馈使用接口，去掉编辑区状态气泡及“已保存 / 未保存”标识；内部草稿检测和未保存离开确认保持有效。成功提示沿用 2 秒清除，失败保留至下一次操作；清除计时器以递增修订号防止覆盖后来的同文提示。插件升级至 1.2.7，最低宿主 0.16.0；已有安装包通过现有重新载入/更新流程更新，不自动改写用户安装库。

验证 SDK 输入/会话失效、后端调用身份、当前状态与乱序/旧会话隔离、面板底栏可见和布局、Notes 保存成功/失败、重复提示计时及构建。保留现有工作区改动，不提交。

## 主结果插件统一规范

结果型插件沿用同一左右分区。旧版 mainResult 的可执行结果仅支持默认复制，由宿主显示“Enter 复制”；结果动作使用已校验的 defaultActionId 对应标题，未指定默认动作但有动作列表时显示“Enter 选择动作”。纯信息结果不显示执行提示。执行中和可重试失败不覆盖右侧提示，结果消费后取消失效的 Enter 提示并提供重新运行按钮。右侧动作标题过长时省略并提供完整悬停提示。

翻译 1.2.1 的结果副标题只显示翻译方向，不拼接快捷键文案；保持原有默认复制及有道服务形态，不扩大权限。无需变更后端或插件公开 API；默认动作标题仅从主程序已有的动作元数据投影到显示快照。
