# 截图元素识别设计（原版 Provider 接入）

用户于 2026-10-29 要求“移除 rust_uia 的修改，回到初始状态，截图仅使用 rust_uia 的编译物和代码能力”。此最新要求替代此前新增轻量接口的方案。独立仓库源码恢复至截图接入前的9cefba7内容，撤回提交ca3b9eb；后续不再修改其源码。已经验证的入口冻结画面、无闪烁遮罩、单击与自由拖框交互继续保留。

## 1. 边界

rust_uia 保持独立仓库和原始源码能力；UiPilot 只通过独立命名管道调用其 EXE 原有的elementtree协议，不复制或重新实现 UIA 遍历。Provider返回元素树数据，宿主读取几何并管理遮罩、输入、桌面取帧及已有预览/输出。原生窗口枚举只用于排除截图覆盖层和确定目标窗口，不替代元素识别。会话选择原有uia后端和非交互读取，不调用元素动作、保存元素库或Provider交互选取界面。截图专用子进程通过原有UIAUTOMA_HELPER_INJECT_MAP配置（非空映射、空进程列表）关闭Helper自动准备，避免树读取触发微信/企业微信注入；不改变用户全局配置或外部源码。

## 2. 探测协议

ping及资产清单要求原有win32_elementtree、win32_inspect_tree_v2、win32_observation_sessions三项能力。已撤掉probe.point，不再要求point_probe_v1。宿主通过elementtree.open_session语义（method为elementtree，operation为open_session）打开指定原生窗口的非交互uia观察会话，再读取有界get_subtree；完成后关闭观察会话。请求和响应使用原有session_id、snapshot_id及节点引用合同，校验JSON-RPC id、业务错误、会话和快照身份。

收集上限为2048节点、64层，响应最多4MiB，初次收集总预算3秒。只有完整、未截断且未超时的树可用于元素吸附。读取原协议的display.position_and_shape物理坐标；忽略无可见矩形的节点，不能因父节点的矩形不包含鼠标就丢弃它的后代。相同矩形去重，选择包含当前鼠标的最小有效矩形；不同几何但同最小面积的竞争候选不冒充唯一命中。

缓存只保留几何，限于当前截图会话及原生窗口身份、位置。排除宿主和Provider的窗口/PID后按原生Z序确定目标窗口，再请求该窗口的树，避免全局按点接口命中截图覆盖层。树未就绪、超时、不完整或窗口身份改变时仍可使用窗口候选和自由框选。不承诺视觉像素分割、动态内容原子快照或所有应用的绝对最小控件。

## 3. 交互与取帧

默认区域模式升级为智能截图。进入时隐藏宿主窗口，等待桌面合成并捕获原始桌面帧；随后显示完整、不透明的输入覆盖窗口。悬停异步探测；命中后所有显示器绘制50%黑色遮罩，元素矩形内部重绘同一原始帧、边界高亮并显示真实像素尺寸。这是视觉镂空，不使用原生透明色键，底层窗口不能通过镂空接收点击。绘制先在计入像素预算的后台位图完成，再一次性发布，避免逐层绘制露出亮帧。

Provider尚未就绪或元素树不可用时可显示明确标注的“窗口候选”，继续自由拖框；独立窗口截图入口保留。元素树准备完成后，鼠标移动从缓存几何中选择候选，避免每个像素重新远程遍历。

鼠标按下只锁定当前已经显示的候选和起点，不隐藏遮罩、不再次取帧；导出始终从入口原始帧裁切，避免点击闪烁。原生鼠标观察器只记录截图窗口拥有捕获时的按下，按事件顺序和唯一手势 ID 配对，使用原始物理坐标匹配后再转换半开边界。鼠标和取消输入始终由截图会话拥有。显示变化或捕获丢失取消。

窗口候选固定在入口快照的位置；发布元素候选前复核查询点的可见根窗口身份、位置及遮挡顺序，发生变化则清除元素候选，不能把新窗口位置套用到旧画面。根窗口内的动态控件仍可能在冻结之后改变；异步 UIA 与桌面帧不是原子快照，元素吸附属于尽力识别，用户可自由拖框准确选择冻结画面的任意区域。

系统拖动容差按按下显示器 DPI 换算物理坐标。未越界的抖动松开后选择按下时元素；越界永久切到拖框，以原始按下点为锚，跨窗口跨屏任意方向；回到原点不切回单击。零面积拖框不提交，恢复悬停；无候选单击不提交。Esc取消。重拍取消保留旧图。空闲Enter选择当前候选，Space设自由框起点，方向键延续物理像素选择。

## 4. 宿主通信

专用后台工作线程持有本会话 Provider 子进程，启动参数唯一pipe和parent-pid，检查ping能力；退出或取消仅关闭本会话进程。主UI/原生消息循环不等待管道。一次最多一个在途请求，等待期间只保留最新坐标。鼠标移动即提交最新位置；完成后通过专用原生消息通知选择线程，不依赖低优先级定时器显示结果。几何、目标身份及候选类型未改变时，不重复绘制整屏。

响应按会话、序号、位置和当前阶段核验。悬停时允许先显示仍包含当前鼠标位置的已完成命中，再对最新位置继续精化；不能覆盖更新的已采用结果，跨出矩形不能复用，无命中只处理最新请求的精确坐标。按下/拖动/取消后晚到响应不能更新候选，按下会提升已处理序号边界。首次树读取允许3秒有界收集，缓存命中不重复远程请求；退出或超时通过独立进程生命周期终止挂起调用。失败保留自由选择，不自动无限重启。Release仅从安装资源加载，debug允许脚本提供暂存EXE路径。复用原有权限、预算和输出会话检查。

## 5. 编译物、dev与Setup

新增 D:/code/.tools/dev-uipilot.py，参考同目录build-test.py。薄入口调用UiPilot仓库内构建/开发工具；路径参数和本地配置确定两个仓库，默认当前已指定目录。每次启动在rust_uia目录运行cargo build --release --locked（目标x86_64-pc-windows-msvc与宿主匹配），利用Cargo缓存；开发允许未提交修改并记录dirty。不得自动拉取/切分支/清理用户改动。只复制EXE和清单到生成暂存目录，失败不得回退旧EXE。

构建共享模块生成commit、dirty、target、构建参数、size、SHA256和ping能力清单；并发构建使用互斥/独立暂存避免EXE与清单混配。开发脚本构建核验后启动现有npm run tauri -- dev，保留Everything、端口配置；退出只清理拥有的进程。

Setup同样从独立rust_uia源码构建，通过Tauri构建钩子覆盖package.py和项目包装器入口 `npm run tauri -- build --bundles nsis`（对话中“直接tauri build”指此入口）。`npm run tauri -- bundle --bundles nsis` 同样在持锁会话内准备一次；绕过项目包装器直接运行 node_modules CLI、npx 或 cargo tauri 不属于支持入口，钩子在缺少持锁会话时拒绝执行，避免资源并发替换；一次构建准备产物，打包前校验同一份。resources显式包含EXE与清单，安装后只依赖资源目录，不需Python/Rust/开发路径。源码缺失、能力不符、构建失败阻断发布。保留既有Everything构建/NSIS逻辑。打包日志增加Provider阶段。安装升级/卸载由父进程退出及进程清理保障资源可替换，不能结束别的Provider。

## 6. 验收

协议参数/负坐标/最小节点/排除遮罩/超时；手势抖动、阈值越界后返回起点、空选区；晚到/错序响应；Provider缺失/崩溃仍可拖框；混合DPI及跨屏镂空；取帧无黑罩边框；点击不触发底层；重拍取消与资源释放。构建失败不复用旧EXE、清单一致性、dev调用链、Setup资源完整性及全库相关回归。真实桌面验收与自动测试分别报告；不自动安装Setup或干扰用户当前应用。
