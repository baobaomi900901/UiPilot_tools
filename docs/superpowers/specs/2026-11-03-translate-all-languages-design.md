# 有道全语言翻译设计

用户于 2026-11-03 确认支持有道文本翻译全部语言，延续已授权的宿主与 SDK 开发范围，在当前翻译隔离工作树实施。

## 语言合同

以 `docs/plugin-sdk/youdao-languages.json` 为核对依据，来自有道官方文本翻译 `/api` 文档，截至 2026-11-03 去重 112 种，83 种标注支持自动识别。auto 仅限源语言，不是具体语言。请求使用精确规范代码；响应语言代码大小写不敏感，归一为规范代码；未知检测仍为 null，目标不匹配仍拒绝。

插件、Runtime JS 桥接、Rust 宿主和 SDK 必须覆盖同一集合，不放开为任意字符串。现有权限、会话过期、输入大小、签名、凭据托管等边界不变。Host 发布版本 0.19.0，插件 1.4.0 最低 Host 0.19.0。旧版本声明不启用新增翻译语种；旧中英合同继续有效。

## 面板

保留两个文本区与现有语言弹层。按中文名、英文名和代码搜索；auto 仅源列表。标记不支持自动识别的语言需要手选。语言偏好保持兼容；检测、交换、复制和请求过期隔离适用于所有语言。文本区 dir=auto，兼容阿拉伯语等方向。服务仍只有有道。不支持的供应商语言方向返回清晰、安全错误，不泄露响应或凭据。

## 朗读

仍使用 Windows SAPI，基于系统声音的真实 locale 映射到语言目录，不把所有语言都宣称有声音。区分简繁中文、塞尔维亚两种书写系统及粤语，不错误回退到其他语言。找不到匹配声音时禁用并说明原因。保持显式点击、互斥播放、停止和会话撤销语义。

## 验证

语言集合一致性、代表性多语种往返与识别、未知代码拒绝、自动识别局限提示、声音 locale 映射、RTL 和键盘搜索。运行插件完整测试、Host bridge/服务/语音专项测试、SDK 类型、构建和新归档校验。真实有道请求和本机声音验收另列，不使用用户密钥进行批量付费测试。
