# 翻译 Panel 宿主能力请求

日期：2026-11-03。状态：供主程序开发代理评估与设计；本文不是已发布 SDK 合同，也不授权插件开发代理修改宿主。

## 用户需求与插件场景

将 `com.uipilot.translate` 从 `submit + mainResult` 迁移为 `submit + panel`。面板上方是可编辑原文框，中间依次为源语言选择、交换方向、目标语言选择，下方为译文框及翻译服务选择器。原文与译文都能复制、朗读。源语言默认自动检测，点击后打开选择面板，既可选自动检测，也可指定语言。服务选择结构支持扩展，首版仅接入有道。

保留插件 ID、`/translate` 启动键及现有用户绑定；迁移需兼容已有主动划词翻译入口。具体插件交互与实施顺序见 [开发计划](../plans/2026-11-03-translate-panel.md)。

## 当前 API 缺口及证据

| 能力 | 当前限制 | 影响 |
| --- | --- | --- |
| Panel 调用有道 | `docs/plugin-sdk/public-plugin-v1.md` 的 Host-managed credential services 小节及 `uipilot-plugin-api-v1.d.ts` 的 `PluginServicesApi` 限定旧式单命令 mainResult，且不能开启 resultActions | 仅改 outputMode 会使服务调用不兼容 |
| 自动检测与语言集合 | `PluginYoudaoTranslationInput` 仅有 en/zh-CHS；`src-tauri/src/public_plugins/host_services.rs` 的 `YoudaoInput::validate` 只接受中英两个互译方向，响应只有 translations | 无法传自动检测，也无法得到可信的识别语言；现有插件汉字正则不是供应商语言检测 |
| Panel 任意文本复制 | `UiPilotPluginPanelApiV1` 没有复制任意文本方法，clipboardHistory.copy 只复制已有历史记录 | 不能复制当前新输入或新译文；不得把历史记录权限当通用复制能力 |
| 朗读 | 公开 SDK 无语音播放/停止合同；`webview_audio_guard.rs` 管理 WebView 静音边界 | 不能把 speechSynthesis、远程音频或解除静音当作已支持能力 |
| 划词入口 | `public-plugin-v1.md` 的 selection.read 小节限定翻译插件旧式 submit + mainResult | 迁移后不能静默丢失快捷键入口，也不能由插件捕获其他应用选区 |

## 建议宿主/API 行为

以下为能力需求，最终接口名称、DTO、错误码、权限与最低版本须由主程序设计确定并发布，插件计划只依赖该发布合同。

### H1：Panel Runtime 翻译及检测

- 为旧式 `submit + panel`、`ui.panel`、`panel.runtimeActions: true` 的合法当前会话开放受控有道服务调用；保持旧 mainResult 插件兼容。
- Panel 通过既有 request → onPanelAction → 宿主服务链路翻译，内容页不直连供应商。onCommand 返回初始化数据，避免挂载前等待翻译。
- 继续要求网络与有道服务独立授权、宿主密钥配置启用、供应商主机白名单；密钥、签名、认证 URL 和供应商原始响应不下发。
- 服务允许源语言自动检测及明确指定语言；响应返回规范化译文、实际源语言（无法确定时明确表示未知）和目标语言。未知不能猜测为英文。
- 发布受支持语言及方向清单，区分源语言、目标语言和自动检测能力。首版至少覆盖简体中文、英语及自动检测；其他语言仅在宿主与供应商映射验证后出现。
- 延续 8192 UTF-8 字节输入限制和现有响应限制；在 SDK 中明确自动检测、同语种、空输入、不支持方向及检测失败行为。
- 同语种明确选择时建议直接返回原文，不发网络请求；自动检测得到目标语言时允许成功返回原文并说明无需转换。

### H2：Panel 文本复制

- 提供会话绑定的纯文本复制能力，要求已声明且已授予 clipboard.write 与 ui.panel。
- 仅当前插件内容 WebView、当前会话可调用；不可借此读剪贴板、模拟粘贴、隐藏窗口或改动外部焦点。
- 明确长度、NUL、空文本限制；建议兼容现有 copyText 的 16 KiB UTF-8 上限。只在 OS 写入完成后返回成功；失败不自动重试。

### H3：受控朗读

- 首选宿主持有的本地系统语音合成；原文/译文朗读不新增远程服务接入。若采用其他实现，先在宿主设计中说明网络和授权影响。
- 发布开始、停止、完成/错误状态合同，并明确权限、文本上限、语言及可用声音查询；不返回任意音频 URL，不解除插件通用音频隔离。
- 同一时刻只有一个活动朗读。新朗读停止旧朗读；同一朗读按钮再次操作则停止。语言没有可用声音时提示原因，不自动安装声音或切换到其他语言。
- 会话关闭/隐藏、插件禁用/更新/卸载、相关权限撤销时停止。旧完成事件不能结束新朗读或更新新面板。

### H4：划词兼容及版本交付

- 将现有翻译插件主动取词入口扩展到合法 Panel，捕获结果经现有宿主路径成为本次 Panel 输入；保持 selection.read 独立授权及现有捕获/恢复边界。
- 捕获失败不得拿旧剪贴板或旧原文自动翻译；捕获中切换目标、取消、撤权或会话失效后不发布旧结果。
- 同步更新宿主实现、SDK 类型与合同、Manifest Schema/CLI 验证及必要最低版本。不要仅提高插件最低版本而缺失对应宿主发布。

## 验收检查

- 有道调用：合法 Panel 请求成功；伪造调用者、无 ui.panel、无网络/服务授权、配置关闭、失效会话均在受控边界拒绝。旧 mainResult 正常工作。
- 顺序 A：请求开始 → 撤权或更换密钥 → 供应商返回；旧结果不发布，新请求使用新授权上下文。
- 顺序 B：请求 A 开始 → 新命令替换 Panel → A 返回；不能更新新 Panel，不能复活旧 request 或旧服务凭据上下文。
- 自动检测及指定中英方向正确，混合文本/无法识别有明确结果；不泄露供应商原始字段或凭据。
- 复制无剪贴板读取或输入模拟；写入失败不显示“已复制”，撤权/过期时拒绝；其他 WebView 不可借用接口。
- 朗读 A → 朗读 B → A 完成：B 继续保持正确状态；隐藏/撤权后停止，迟到事件不能复活。缺少声音可解释且无联网安装。
- 划词：命令改名后仍正确，升级保留绑定与授权；无选区、捕获失败及过期捕获不触发旧内容翻译。
- 取消插件升级或新增授权时，原插件、配置与数据保持原状。
- 自动化验证使用假供应商、假剪贴板和假语音驱动。真实供应商调用、系统剪贴板写入、朗读及跨应用取词由用户主动进行最终 Host 验收。

## 交付与边界

主程序开发代理需先产出正式接口设计及验收证据，再交付 SDK 合同与可运行 Host。相关现有定位点为 `src-tauri/src/public_plugins/host_services.rs`、`src-tauri/src/public_plugins/activation.rs`、`src-tauri/src/public_plugins/webview_audio_guard.rs`、`src-tauri/src/selection_translation.rs`、SDK 合同及 CLI；这些仅为调查入口，并非插件任务的写入范围。

H1–H4 未交付前可以做插件的离线状态与 UI 测试，但不得以假桥接成功宣称完整插件可在当前 Host 工作，也不得交付破坏现有翻译的 Manifest 替换。
