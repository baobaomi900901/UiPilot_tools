# 密钥配置管理页重构

## 目标与现状

将设置中的密钥配置改为翻译、OCR、大模型三个分组的管理列表。分组外框、边距、行高、图标、开关与权限页一致；点击名称进入独立详情页。

现有 `CredentialSettings` 仅维护 React 草稿，没有持久化。当前仅有有道翻译验证命令；百度翻译、百度 OCR 和大模型验证需要新增宿主能力。此次实现真实本地存储，不将临时草稿视为已保存配置。

## 列表

- 页头：密钥配置标题与添加配置按钮；下方搜索名称与服务商。
- 三个分组：翻译 / Translation、文字识别 / OCR、大模型 / LLM。
- 各行：图标 | 名称（可点击）| 开关 | 删除图标。
- 使用权限页的 28px 图标容器、14px 名称、small 开关、44px 行高、10px 列间距、6px 分组圆角及主题 token。
- 翻译仅允许有道与百度；OCR 仅允许百度，不提供有道 OCR。
- 删除需要确认，说明会删除本机保存的此项配置；删除后可重新添加。
- 开关表示此配置是否可供使用，不等同于插件的网络权限，不触发验证请求。
- 不自动更改插件权限；本轮不将配置自动绑定给已有插件。

## 详情

- 页头：返回 | 配置名称，沿用插件详情的尺寸及返回焦点规则。
- 名称可编辑；凭据输入默认遮蔽，可切换查看本次输入。
- 有道翻译：名称、App ID、App Key。
- 百度翻译：名称、App ID、密钥。
- 百度 OCR：名称、App ID、API Key、Secret Key。
- 用户已明确：大模型首版仅 DeepSeek。详情为名称、API Key；固定官方 API 地址，不开放自定义 Base URL，不预设模型名。通过官方模型列表接口验证认证，不宣称余额或生成额度已经验证。
- 截图中的“模式类型”“显示词典”属于翻译消费行为。目前没有对应宿主能力，需明确语义后再接入；不得做成无实际效果的可操作控件。
- 验证按钮只在必填项完整、没有请求进行时可用。成功后保存当前验证过的配置，显示“验证成功，已保存”。失败保留草稿及原有已保存配置。
- 修改凭据后，旧验证结果立即失效。验证期间禁止编辑并阻止离开，避免当前请求与后续编辑混淆。提交时再次检查版本，不得保存已删除的条目或覆盖并发更新。
- 离开未保存详情时提示保存状态；可留在当前页面或放弃本次修改。
- 设置底栏展示当前提示；无提示时显示返回快捷键，版本号保持在右侧。状态不依赖系统通知。

## 存储与验证边界

- 普通元数据与密钥由宿主管理，密钥使用 Windows 用户级 DPAPI 加密保存；不写入前端 localStorage 或普通设置明文。
- 列表仅返回配置元数据与密钥是否存在，不返回历史密钥明文。编辑已有配置时空密钥字段表示保留原值，用户可输入新值替换。
- 只有主窗口能调用管理及验证命令。宿主校验类别、服务商、长度及必要字段。
- 各服务验证通过宿主执行，具备超时、响应大小限制和固定错误映射；不把请求凭据、供应商响应原文或密钥写入日志。
- 四种服务都使用固定官方地址，禁用自动重定向；不将密钥转发到其他主机。
- 自动化验证使用合成凭据与离线传输替身，不访问用户真实服务，不启用用户的真实配置。

## 验收

- 三类分组和服务商限制正确，内外边距及深浅主题与权限页一致。
- 名称进入详情，返回与 Escape 恢复合理焦点；输入框方向键不触发 tab 切换。
- 添加、验证保存、重启读取、启停、确认删除可独立验证。
- 验证失败不覆盖旧配置；乱序响应、编辑中返回、删除中返回等场景不会错误保存。
- 密钥不出现在列表 DTO、普通配置文件、错误日志或测试产物中。

## 实施范围确认

本轮聚焦配置管理与验证，暂不提供没有消费方的模式类型及显示词典选项。四个固定服务分别管理一项可自定义名称的配置，可删除并重新添加。

百度 OCR 验证 API Key / Secret Key 的令牌认证及 OCR scope；App ID 作为配置项保存，不声称校验其与密钥的对应关系，也不声称识别额度可用。详情明确说明验证范围。

## 验证接口依据

- [DeepSeek 模型列表](https://api-docs.deepseek.com/api/list-models/)：GET /models，检查认证及模型列表响应结构，不进行生成请求。
- [百度翻译通用接口](https://fanyi-api.baidu.com/doc_bd/21)：固定官方地址，按 appid + q + salt + 密钥生成 MD5 签名。
- [百度 Access Token 获取](https://ai.baidu.com/ai-doc/REFERENCE/Ck3dwjhhu)：固定 OAuth 端点及 client_credentials 参数，检查令牌与 OCR scope。
- 有道翻译沿用已有宿主 `validate_youdao_translation` 的 v3 签名流程，新增统一超时、响应长度与错误边界。
