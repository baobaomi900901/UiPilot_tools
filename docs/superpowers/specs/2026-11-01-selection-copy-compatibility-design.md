# 划词翻译的临时复制兼容

用户已确认同时处理 UiPilot 与 Windows Win+V 历史，并追加要求缓存、恢复原剪贴板。本设计替代此前 UIA-only / 不恢复的限制。实现限宿主，不修改 rust_uia，也不改变翻译插件的服务调用。

## 流程与权限

优先读取焦点 UIA 选区。仅当控件没有 TextPattern 时进入兼容路径；空选区、密码控件、权限撤销、目标切换和超时不触发复制。沿用 selection.read 授权及最新请求身份。捕获前台目标后等快捷键释放，在原窗口只模拟一次 Ctrl+C，读取后通过现有命令投递文字，不模拟粘贴或 Enter。

## 剪贴板事务

复制前完整物化支持的剪贴板格式到内存并准备恢复资源；文本、DIB/PNG/Bitmap 图片、文件列表及可安全复制的全局内存格式需要保留。注册格式只接受已知的自包含数据格式；不能仅凭 HGLOBAL 有效就假设其内部没有进程指针。未知应用私有/OLE 格式、不支持的句柄格式或超限数据均在复制前终止，不以纯文本备份冒充完整备份。原内容不写入磁盘或日志。

OLE 的 `DataObject`、`Ole Private Data` 是传输附加格式，不按普通数据复制其旧对象引用。遇到它们时，先释放剪贴板锁，通过 `IDataObject::EnumFormatEtc` 验证每个声明的实际数据格式都存在于 Win32 格式列表，且能物化为已支持的 HGLOBAL/GDI 数据；虚拟文件流、索引内容、目标设备专用数据及无法覆盖的格式均中止。重新加锁后复核原序号与所有者，确认没有新复制，才物化全部实际数据格式。恢复不重新写入这两个附加格式；旧 OLE 对象本身不作为备份。仅包含附加格式、没有实际数据的对象不接受。

微信文字附带的 `WeChat_RichEdit_Format`、`QQ_Unicode_RichEdit_Format`、`x-application-mimetype-xwechat` 按独立策略支持：必须全部出现在已校验的 OLE 格式声明中，存储类型为 HGLOBAL、内容视图、无索引或目标设备；满足后按原字节备份和恢复。不将这些格式直接加入免 OLE 校验的通用序列化格式白名单，也不放开未知私有格式。

`FORMATETC.tymed` 按可选存储介质的位集合解释：包含所需 HGLOBAL（或位图的 GDI）即可，允许同时提供 ISTREAM 等替代读取方式；只提供流而不提供所需内存介质仍拒绝。Windows 在 Win32 恢复后通常声明 `HGLOBAL | ISTREAM`，后续划词请求须继续接受同一份可物化数据，不能要求整个标志值与 HGLOBAL 完全相等。

仅接受复制前后序号发生变化、所有者属于原目标进程、前台未切换的 Unicode 文本。持有剪贴板锁时复核序号和所有者，防止检查后再写的竞态。读取完成即存入宿主内存，可恢复剪贴板后再向插件投递。恢复仅针对仍属于本次复制的序号；用户新的复制或输入使旧恢复失效。禁止无条件恢复、清空全部历史或按文本删除旧记录。失败路径也尝试有条件恢复；未完成恢复/清理必须准确反馈，不能声称成功。

## 两套历史

UiPilot 使用独立事务门：观察器读取至入库与临时复制互斥。复制与恢复产生的准确序号被排除；其他序号正常记录。事务结束后仍能识别延迟到来的观察回调，不按“下一个事件”盲目跳过，不改动相同内容的旧记录。

Win+V 在复制前获取既有条目的 ID 集合；只检查本次之后新增、内容与取词一致的候选，旧 ID 永不删除。使用 Windows 的单条删除接口，不清空历史。恢复写入标记为不进入历史/云同步。系统历史关闭时视为无需清理；访问拒绝或无法取得基线时停止兼容复制。异步历史查询和清理有截止时间；无法可靠归属的条目不删除。系统历史采集延迟、系统策略或第三方剪贴板管理器不在绝对可控范围内，需实机验收。

## 验证

历史接口在 UIA 的 MTA 作用域结束后使用独立的 STA 作用域，并在异步等待期间分批处理该工作线程的消息，保留截止时间及归属检查。2026-11-01 本机只读状态探针确认：MTA 调用 `IsHistoryEnabled` 返回 `RO_E_UNSUPPORTED_FROM_MTA`（`0x8000001D`），STA 调用成功。回归测试验证真实 apartment 类型和消息分派，但不访问剪贴板内容。

测试使用伪造的选区、剪贴板及历史记录，不自动读取用户真实历史或调用翻译 API。覆盖 UIA 优先、无新复制不读旧内容、目标/取消检查、剪贴板更新后不恢复、全格式备份失败前置终止、重复文本旧历史保留、复制与恢复不入 UiPilot 历史、普通后续复制正常入库、权限撤销后不投递。

实际微信、记事本、原剪贴板文本/图片/文件、Win+V 检查由用户主动触发。保留现有分支及未提交修改，不自动提交或修改 rust_uia。
