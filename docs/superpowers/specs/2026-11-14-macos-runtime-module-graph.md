# macOS 安装快照模块图

承接主程序运行协调与原样 ESM 实验，移除真实包诊断的 2 KiB/32 模块/ASCII 路径实验限制。本单元实现宿主可复用的不可变模块图及真实 QuickJS 诊断适配；生产签名传输仍关闭，不修改 SDK 权限和 Windows 行为。

## 数据和解析

模块图只来自 VerifiedPackage 已拥有的资源，不重新读取开发目录。入口取已验证 manifest.runtime.entry，收集包内 JS UTF-8 源码，沿用包文件数、单文件、总量、深度与路径规则；拒绝重复、大小写/NFC 别名、目录/文件冲突和缺入口。图不携带用户安装绝对路径。JS 源码中的 NUL 拒绝。

resolver 必须先确认导入者存在，再对 `./` / `../` 相对名称做组件规范化；不得逃出包根。使用精确 Unicode/空格路径，不做 URL 解码、大小写折叠查找或扩展名补全。URL 查询/fragment/百分号形式、绝对路径、裸包名、node/std/os、原生库与字节码均拒绝；缺模块不回退磁盘。loader 独立验证图成员，带 import attributes 的请求拒绝。循环依赖、live binding、静态/动态导入和 top-level await 由固定 QuickJS 模块语义完成。

## 接线与限额

Host 在调度前从当前安装快照创建模块图，传输取得该图而非从文件系统收集源码；升级后的新请求取得新图，已捕获的旧图不受源目录修改影响，旧授权仍由现有取消/完成票据失效。

诊断 helper 的首个初始化帧可承载有界图（24 MiB 上限；现有 package 快照 5 MiB 限制仍生效），只允许发送一次。随后双向 RPC 仍使用原 4 KiB 单帧/8 KiB 总量预算，不因源码变大放宽回复限制。先检查帧长度再分配，首帧也执行重复 JSON key/深度校验。父 deadline/取消、stderr 上限、唯一完成和 kill+wait 不变。单独记录诊断引擎预算，不把它称为生产沙箱或性能承诺。

## 验证

纯逻辑覆盖边界与不存在的导入者；真实临时安装包经协调器、真实数据绑定和 QuickJS 子进程执行 >2 KiB 源码、>32 文件、Unicode/空格路径、循环/re-export/dynamic import/TLA。替换源目录后只执行安装快照；错误图、缺模块、越界/属性/URL/系统模块拒绝不发布结果；每次退出回收，失败后新请求成功。既有权限撤回、升级、设置与归档诊断回归。

本轮不操作 GUI、个人插件库或系统授权，不需要人工安装包；生产同包双端运行通过数不增加。下一阶段仍需完整生产隔离适配及真实能力服务。
