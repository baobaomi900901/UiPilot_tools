# 本地插件基座分阶段交付设计

日期：2026-10-23。范围：Windows x64 宿主与本地 `.uipilot-plugin` 安装；不建设在线商店、在线发布、自动下载或云同步。用户已授权主 agent 自主规划、分派实现与评审。

## 目标与完成标准

常见效率插件可以独立开发、打包、安装、交互、保存数据和升级，通常无需修改宿主。旧 v1 插件继续工作；失效请求不能写入新会话；插件故障可以定位和恢复。完整基座的验收使用多命令工具、认证网络工具、可编辑面板、用户选定文件工具以及现有剪贴板/番茄钟，而不是以新增 API 数量衡量。

## 方案选择

选择渐进扩展：先建立全仓验证门禁，再以端到端插件场景交付新能力。直接一次性改 v2 会同时影响 manifest、运行时、收藏和设置；仅给每个示例增加专用宿主接口会继续扩大耦合。每个阶段都有独立设计、实施计划、原子提交和评审，阶段完成后再冻结依赖它的下一阶段合同。

## 工作区与授权边界

开发基线为 `81144f4` 的独立 managed worktree。`D:/code/UiPilot_tools` 的未提交设置/凭据改动不带入、不提交、不覆盖。原目录 CSS 导入和命令数量测试失败属于这些改动，不在本分支冒充已修复。开发、测试、构建和本地提交由当前授权覆盖；真实系统安装、服务变更、真实凭据请求、发布或向远程推送不是本计划的自动步骤。

## 通用约束

- 单个写代码 agent 执行一个任务；只读调查和评审可并行。相依任务需先通过规格与质量评审。
- 主 agent 维护 `.superpowers/sdd/local-foundation/` 日志、任务 brief、报告和 diff。恢复会话时先核对记录与 Git。
- 新能力采用明确最低宿主版本；不能静默改变旧 manifest、网络或执行权限语义。
- 安全校验、会话身份、取消、焦点归属和失败恢复写入阶段设计，不能靠示例约定代替。
- 不为本计划提前实现任意 Shell、无限后台执行、插件间调用或多窗口。
- Windows 原生焦点、剪贴板粘贴和安装器 VM 测试保留独立人工验收，不由单元测试通过推断。

## M0 设计合同

### 验证协调器

新增 Node ESM 脚本 `scripts/verify-local-foundation.mjs`，根 `npm run verify:local` 执行它，`npm run verify` 是同义入口。`--list` 仅打印实际阶段和发现数量，不执行构建/测试。工作目录根据脚本位置确定，不依赖调用者 cwd。进程使用参数数组，禁止将路径拼接为 shell 命令；Windows npm 通过当前 npm CLI 路径或 PATH 定位的 Node/npm CLI 执行，不使用 shell=true。

依次执行：协调器自身测试、前端测试与构建、Rust `--lib --offline` 测试、Rust manifest schema `--check`、CLI 完整 verify、公开插件 Node 测试、公开插件 SDK contract 类型检查、每个参考 package 的 CLI 校验。按实际磁盘目录递归发现 `examples/public-plugins` 的测试/合同/package，排序稳定；根缺失、零测试、零包、非普通条目/符号链接导致明确失败，不能默默跳过。没有 sdk-contract 的单个示例不强制新增，但全仓 contract 检查集合不能意外为空。

任一阶段错误或 spawn 失败立即停止，最终退出非零，并标明阶段；不自动修生成文件、不运行安装器、不联网调用服务、不执行任何插件 Runtime。测试可执行自己的 mock Runtime，实际包校验仅静态读取。运行过程可以生成正常构建和临时测试产物。输出日志不包含秘密值。

### 参考包断言

`demo-panel` 使用当前固定 manifest：version 1.0.5、minimumHostVersion 0.3.3、hostKeys ArrowDown/ArrowUp/Primary+N/Tab/Shift+Tab。`translate` 包根严格集合为 dist/icon.png/plugin.json。保留未知文件拒绝，禁止用通配忽略掩盖差异。生产示例功能和开发凭据不改动。

### 文档与验证

根 README 描述当前 Windows 支持、工具链、开发/构建入口、全仓和聚焦验证、源码地图、本地安装插件和范围限制。必须说明浏览器预览/单元测试不能替代真实宿主验收。记录已知 React act 与 Ant Design 警告，不以关闭断言方式消除它们。自动协调器测试覆盖发现顺序、路径含空格、空集合、非法条目、阶段顺序、非零失败短路和启动失败；测试用受控假执行器，不运行整套构建。
