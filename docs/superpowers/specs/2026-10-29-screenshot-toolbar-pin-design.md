# 截图图标工具栏、贴图与默认保存位置

状态：用户于 2026-10-29 确认实施。此前八方向调整与桌面保存已获用户实机认可。

## 范围与方案选择

元素探测继续调用 rust_uia 独立 EXE；不修改、复制或重新实现 rust_uia 源码。保留现有悬停、防抖自由框选、冻结画面、50% 遮罩和八方向调整。

推荐扩展现有原生遮罩工具栏，新增独立原生贴图窗口；通用设置沿用现有 React 设置界面与 SettingsStore。原生贴图直接使用已裁剪像素，便于保证内容物理尺寸与选区一致，不经过预览页加载。

备选是为每张贴图创建 WebView，能复用前端组件，但会增加窗口加载、像素缩放和内存管理成本。本次推荐原生方案。实现时把工具栏、贴图窗口各自封装，避免继续将逻辑堆入 overlay.rs。

## 工具栏

从左到右固定为四个 Lucide 图标：X（终止截图）、Pin（贴图）、Save（保存）、Copy（复制）。按钮只显示图标，提供中文可访问名称、悬停提示和键盘焦点。按用户后续要求，深色统一黑底白线图标，浅色统一白底黑线图标；取消不使用红色，保存不使用反色填充。图标外部不绘制包围框；默认及鼠标操作时只显示图标，Tab导航后用同色底部短线提示键盘焦点。按钮命中尺寸 28 DIP。

工具栏整体沿用现有保存按钮的定位：选区右下外侧、右边缘对齐、间隔 8 DIP；空间不足时移到上方或屏幕内，避开调整点。调整过程中隐藏，松开后重新定位；同时支持负坐标和不同 DPI。

| 动作 | 结果 |
| --- | --- |
| 终止截图 | 关闭本次遮罩与该会话旧预览，释放资源，界面保持隐藏至托盘，不重新显示启动器，不保存或复制 |
| 贴图 | 从冻结画面裁剪当前选区，成功创建贴图后结束本次截图 |
| 保存 | 保存 PNG 到配置的默认目录，成功后结束本次截图 |
| 复制 | 将当前裁剪图像写入剪贴板，成功后结束本次截图 |

所有输出只包含冻结画面中的选区，不包含遮罩、调整点、工具栏和贴图阴影。输出中禁止重复提交；失败保留当前选区与错误提示，可重试或选择其他动作。

Tab/Shift+Tab 在八个调整点和四个动作之间移动。按钮获得焦点时 Enter/Space 执行该按钮；调整点获得焦点时 Enter 保持原有保存行为，方向键调整选区。Esc与终止按钮采用相同的隐藏到托盘行为，Ctrl+C复制；拖动中不提交输出。已生成的独立贴图不因终止另一次截图而关闭；程序继续在托盘运行。

## 贴图窗口

贴图是独立、无标题栏、置顶的浮动窗口，初始图像位置和大小与选区的物理坐标、物理像素一致。图像不增加内边距，不因边框或阴影被裁切；阴影向外扩展。

按用户指定的顶部光源绘制阴影：上边较轻，下方更深、更远，左右柔和过渡。仅贴图窗口使用此投影，这是用户明确要求的 UI 规范例外。

左键拖动图像移动窗口；跨 DPI 显示器时保持图像的物理像素尺寸。聚焦后 Esc 关闭当前贴图；右键菜单提供“关闭贴图”，便于发现关闭方式。阴影区域不拦截底层应用的点击。

支持多张贴图同时存在，互不替换；关闭一张不影响其他贴图，也不影响新的截图会话。退出 UiPilot 时释放所有贴图；本轮不持久化贴图、不增加缩放或标注功能。正常新的桌面截图会包含当时可见的既有贴图。

只有贴图窗口与像素内容准备成功后，才结束遮罩；创建失败时保留选区。贴图持有像素预算配额直至关闭，超出预算时报告错误而不无界分配内存。

## 默认保存位置

在“设置 → 通用”的截图快捷键附近新增“截图默认位置”：显示当前完整路径，提供“选择文件夹”和“恢复桌面”。使用系统文件夹选择器；取消选择不修改设置。选择成功并持久化后立即反馈，重启仍保留。

配置存储为可空路径；旧配置缺失该字段或恢复默认时为 null，动态解析系统真实桌面，支持重定向和 OneDrive 桌面。自定义路径须为绝对目录路径，保存配置时检查目录存在；实际输出仍检查目录状态和写入结果。普通设置更新不得覆盖或清空此配置。

每次进入截图时读取已提交的目录快照，本次输出使用该目录。继续采用现有 PNG 文件名、同名追加序号和无覆盖发布。目录后来被删除、断开或不可写时保留选区并提示错误，不擅自换目录。

按用户后续要求，截图所有动作均不发送系统通知、不发布消息中心记录。保存、复制、贴图成功后静默结束；取消也不推送。失败仅保留截图界面内的错误提示，不通过消息推送报告。
