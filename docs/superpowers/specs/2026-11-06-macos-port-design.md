# UiPilot Apple Silicon 首版宿主设计

本规格依据[实施计划](../plans/2026-11-06-macos-port.md)及[逐步验收](../plans/2026-11-06-macos-port-steps.md)。状态：进入开发；原型和发布验收分别记录，未验证的平台不能标记通过。

## 支持矩阵与部署下限

目标为 M1 系列（包括 Pro/Max）及后续 Apple Silicon，单一原生 arm64 产物。候选下限 macOS 15.7.4，构建目标、Info.plist 与随包 Mach-O 均须相容。首版支持单实例主窗口、菜单栏、普通组合快捷键、应用结果、打开/激活、主题和快捷键持久化。文件搜索、凭据、插件、截图、输入注入、通知、登录项和进程工具仅在平台后端和负面测试通过后逐项开放。

实机行 A 为 M1 系列 + 15.7.4，B 为后续芯片 + 较新系统（2026-11-06 按用户决定跳过，不作为本轮门槛，兼容性未实测）；Windows 原生回归单列。开发机是 arm64 macOS 15.7.4 (24G517)，Command Line Tools 的 SDK 为 15.2，已安装 Node 22.22.1。已用隔离安装的 Rust/Cargo 1.96.1 完成本机 arm64 构建。完整 Xcode 与 CLT 的可用性分开记录。系统或工具链更改需要重跑对应验收，不能默默提高部署下限。

## 宿主装配与 IPC

生产 Windows 入口的 setup_production_lifecycle 目前读取 credentials、汇率、旧插件、消息、快捷入口、设置并创建 runtime；绑定 Panel/Find 焦点控制器。Builder 注册 Everything、Win32 相关状态，退出路径亦读取这些状态。Mac 装配只创建 main、设置、应用缓存、结果注册表、快捷键及托盘，并只释放实际创建的资源。Windows 保留现有阶段与回滚语义。共享层禁止无条件取 FileIndex、PluginService、Find 或登录项的 State。主程序、schema 生成器、测试和开发 instrumentation 须分别可构建；生产测试不使用精简 instrumentation 入口取代正常启动。

宿主提供版本化的只读能力快照，由受信本地 main 获取，前端在 src/main.ts 的监听预注册和 core.start 前读取。缺少能力时不注册对应监听，不加载后台服务；请求失败显示可重试状态。后端先核验调用窗口与来源，再核验能力，然后取状态；禁用的命令和旧配置不能启动进程或执行插件。Mac 权限只授予首版入口；外部导航不获得 IPC。旧插件、公开插件和凭据两条存储链均保持不可达。Windows 插件兼容性继续按现有 SDK 判定。持久化复用现有 app_data_dir/设置格式；临时文件在同目录完成替换，失败保留旧数据。Mac 首版启动和改键不得获取、读取或更改系统登录项。

## 应用发现与执行

由宿主从 /System/Applications、/Applications、~/Applications 发现应用；扫描子目录，到 .app 即停止。跳过链接、越界和不可读项，有效快照不因单项损坏丢失。优先使用本地化展示名，退回普通名称或包名。以 bundle ID 去重，同 ID 优先系统、共享、用户目录，等优先级按稳定路径排序；缺少身份或启动元数据的包不暴露。路径与文件身份保存在宿主，结果使用稳定 ID 和已有 request/result 注册表，不把可执行路径作为 IPC 参数。Windows 的快捷方式/AUMID 身份不变。

缓存沿用 AppCache 的串行刷新和不可变读快照，刷新失败保留旧快照。沿用应用排名。执行前核对窗口、结果有效期、路径仍在允许目录并指向扫描时的对象；失败不启动替代对象。通过系统应用打开接口启动或请求激活已运行实例。系统接受请求不等于前台切换成功；返回明确结果，保留重试入口。

## 唤起与退出

使用菜单栏常驻、无常驻 Dock 图标的策略。首次组合键候选 Option+Space，冲突时不覆盖系统或其他程序的注册；菜单栏始终提供显示与退出。快捷键替换先尝试注册，持久化失败撤销候选、恢复旧绑定；不触及输入监听和登录项。单实例再次启动、菜单和快捷键走同一唤起路径。主界面显示并激活后聚焦输入，Esc 与外部失焦隐藏；每次展示使用会话身份，旧失焦、晚到的应用启动回调不能隐藏新会话。输入法确认 Enter 不执行结果。关闭窗口隐藏，显式 Quit 停止注册、清理资源并退出。验证原型时先检查不改变用户桌面的部分，真实切换前台交由人工测试。

## 分发与验收

构建使用仓库锁文件，Windows 在原生 runner 使用已有 Provider 源码、Everything 及 NSIS 工作流。Mac 开发调用本地 Vite/Tauri，原生构建只打包 Mac 使用的资源。共享变更分别在两边验证，失败或缺失材料按实际记录。内部测试可使用本地包；公开发布需在授权身份下签名、公证并验证 Gatekeeper。保存最终 DMG 哈希、签名状态、每个设备的系统 build 及结果。两台 Mac 必须用同一份交付包走完整的菜单/快捷键唤起、搜索、打开、激活、隐藏、再唤起及退出流程。

第一阶段人工检查为开发与生产 WKWebView 能否加载、受信 IPC 成功、外部来源 IPC 拒绝、应用发现和真实唤起/焦点。原型通过不代表交付包通过。Windows 生产安装回归单列记录；本轮跳过的较新芯片行保留未实测状态。后续文件搜索、系统集成与插件安全合同按计划 Tasks 8–10 独立评审。
