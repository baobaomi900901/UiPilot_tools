# 统一 Ctrl+K 操作面板

采用用户确认的方案：右下角固定“操作 Ctrl+K”入口，状态文字在左侧，移除底栏展开的快捷键提示。面板仅显示分组与“图标、名称、快捷键”，不显示点击或方向键使用说明。现有快捷键保持有效。

## 表现与交互

主程序维护共享 DOM 组件。普通结果和设置在主 WebView 展示，公开 Panel 在宿主注入的同一组件内展示，避免原生子 WebView 遮挡主页面弹层。面板在底部右侧向上展开。当前对象操作在前，当前功能通用操作在后。支持方向键、Home/End、Tab、Enter、鼠标；Esc 与 Ctrl+K 只关闭菜单并恢复打开前焦点和输入选区，不执行宿主隐藏。禁用项显示原因并不可执行。菜单单次执行，异步失败显示固定错误，不泄露异常内容。

## Panel 合同

新增 `onActions(provider)` 注册同步操作提供器，返回 context/global 两组，最多各 12 项。每项有唯一 id、title、可选 shortcut/icon/disabledReason 与 run 回调。数据仅在该插件 WebView 内使用，不跨插件共享，不增加系统权限。宿主验证结构、长度和图标枚举，使用 textContent 呈现。提供器根据 source=hostInput/content 与打开前的 DOM 焦点创建闭包，捕获具体对象；菜单关闭、重新提交、替换面板后旧回调不得执行。

主页面通过仅 main 可调用的命令打开当前会话的内容菜单；内容 Ctrl+K 由宿主 bootstrap 拦截。Host 输入菜单补充搜索动作，带主页面创建的单次 ticket 请求主页面提交；仅同一会话、ticket 和未变化的输入接受。关闭 Host 输入菜单调用既有 focusHostInput 流程；内容菜单本地恢复原元素及选区。Panel 更新时菜单作废且不抢焦点。菜单打开时隔离插件自己的快捷键，避免 Esc 误隐藏或 Enter 误复制。

## Notes

主输入：进入目录（↓），宿主搜索（Enter）；目录：编辑（→）、复制并隐藏（Enter）、重命名、删除；正文：保存（Ctrl+S）、复制正文。通用：新建（Ctrl+N）、返回主输入（Ctrl+F）。弹窗已打开时不打开操作菜单。菜单捕获笔记 ID，执行前核对，禁止作用到替换后的笔记；保留保存后回目录、未保存确认及复制隐藏逻辑。

## 验证

共享菜单测试覆盖无说明文案、分组、禁用、焦点/选区恢复、单次执行、键盘隔离与失效；桥接覆盖会话/调用者鉴权、Host 提交票据；Notes 覆盖三种焦点来源和草稿保护。使用合成笔记及离线预览，不读写真实用户笔记或调用真实翻译服务。当前分支保留其他改动，不自动提交。
