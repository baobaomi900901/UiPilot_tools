# Mac 主窗口跨屏位置保持修复

上一候选 `ae687c0` 已由用户验证：中文输入法确认回车及下一次正常 Enter 均符合预期；主窗口可以拖动，设置显示当前生效快捷键。新增问题限定于跨屏：内置屏内隐藏/再唤起能保持位置，拖到外接屏后隐藏再唤起却回到原屏幕。用户当前快捷键已改为 **Shift + 空格**。

## 本轮范围

统一主窗口定位链的 macOS 逻辑坐标，优先保留窗口当前可见位置；屏幕移除或工作区变化后才修正不可见位置。不增加退出后的磁盘位置持久化，不修改 Windows、Find、快捷键或登录项逻辑，不改变焦点和展示会话规则。

锁定依赖源码依据：Tao 0.35.3 的 `platform_impl/macos/util/mod.rs::cursor_position` 将全局逻辑鼠标位置乘主屏 scale，而 `monitor.rs::from_point` 直接查询 CGDisplayBounds 逻辑范围；`window.rs::outer_position` 用窗口当前 scale，`set_outer_position` 在排队前按当前 scale 解码；Tauri runtime 的 Mac work_area 按各目标屏 scale 转成 physical。旧宿主直接相传、混比，并每次优先鼠标屏，导致外屏定位可能误回退到主屏。新实现必须避免以某一屏的 physical 值作为全局统一坐标。

## 复验（对话中一次一个动作）

1. 退出旧应用，安装新候选到“应用程序”，从安装副本启动；保留用户的 Shift + 空格。
2. 在内置屏拖动主搜索框，点击桌面隐藏，再用 Shift + 空格唤起：应仍在拖动后的位置。
3. 将同一主搜索框拖到外接屏右侧，点击该屏桌面隐藏，再唤起：应仍在外接屏刚才的位置。
4. 将鼠标移回另一块屏幕再唤起：只移动鼠标不应把已有效放置的窗口拉回原屏。
5. 有方便条件时验证负坐标/上下排列及拔掉外接屏后的可见回退；没有执行的场景保持未验证，不要求测试者立即改变显示器配置。

## 实现与自动证据

主线程读取窗口几何后按窗口 scale 还原；各显示器工作区按各自 scale 还原；鼠标按主屏 scale 还原后才查询所属屏幕。纯策略按窗口和可用工作区的最大交集选择所在屏幕，在需要时约束到可见范围；完全脱屏才使用鼠标屏/主屏/首个有效工作区回退。恢复尺寸时总是先 Resize 再 Move，避免原生调整尺寸改变左上角；位置尺寸均未变时零原生写入。原生异步队列的真实短暂展示与热拔插边界仍需实机验证。

新增纯策略用例先 5 项失败，修复及补充后 `cargo test --lib macos_host::` 共 22 通过；含 7 项新增定位测试。双预览特性集成库测试 **443 通过/8 默认忽略**，all-targets 检查退出 0。日志 `/private/tmp/uipilot-placement-{red,green}.log`、`/private/tmp/uipilot-cross-display-{tests,check}.log`。独立审核 PASS，未运行 GUI 或修改实际显示器。前端及 Windows 代码未变，未重复跑前端全套，不把原生测试忽略项或未执行的设备测试算作通过。
