## 先测 Mac 主程序

先完成 1–4，反馈后再做剩余项目。每项记录通过/失败/未测；失败时附操作、实际现象和截图即可，不必提供个人文件正文。

1. **安装与旧功能回归。** 在交接目录运行：

   ```sh
   sh preflight-macos-42a094b.sh ./UiPilot-Mac-70pct-0.19.0-arm64-42a094b.dmg
   ```

   预检通过后，从菜单退出旧 UiPilot，将 DMG 中的 app 替换到“应用程序”，从“应用程序”启动。不要从 DMG 内直接运行。若系统阻止启动，保留提示并反馈，不修改系统安全设置。使用现有快捷键连续唤起三次，输入中文“计算器”、打开计算器，Esc 隐藏。主题和现有快捷键应保留。

2. **计算与显式复制。** 输入 `2+2`，应显示 `4`；选中结果按 Enter，再粘贴到临时文本中，应为 `4`（此操作会替换剪贴板文本）。输入 `1000 mm to in`，应为 `39.3701 in`；`today + 1 day` 应为设备本地日期的明天；`Mumbai time` 应显示孟买当前时间。货币换算暂不可用是预期，不要求联网换汇。

3. **网页搜索。** 输入普通查询 `中文测试 & A B`，选择网页搜索结果，应在默认浏览器打开当前引擎，并保留完整查询内容。设置中切换搜索引擎后再试，应打开新引擎。仅输入查询时不应自行打开浏览器。

4. **登录项预览。** 在设置找到“登录时启动”，先记录原状态。启用后核对应用状态与系统登录项；如显示“等待系统允许”，按界面入口到系统设置核对，不反复点击启用。可在系统设置关闭该项后回到应用刷新，显示应反映系统现状；在“等待系统允许”状态使用“停止注册”；若处于“已启用”状态则取消勾选，两者结束后均应不再登记。结束时恢复原状态。此项会改变登录项；真实注销后重新登录的自动启动可另找方便时间验证，未做则记为未测。

5. **文件搜索授权回归。** 搜索之前已命中的文稿中文 PNG，确认中文/emoji 路径结果与打开、Finder 定位。退出并重新启动，核对授权是否保留；如要求重新授权，记录现象。再测试“停止并忘记文稿”，确认结果移除且重启后不恢复授权，最后按需要重新授权。不需要移动或删除原文件。

6. **双击 Command（待集中验收项）。** 记录双击 Command 并保存；若界面需要输入监控权限，按提示由本人决定授权，再验证唤起、重启保留及撤权后的可理解提示。普通快捷键应继续可用。没有完成权限授予/撤销的场景分别记为未测。
