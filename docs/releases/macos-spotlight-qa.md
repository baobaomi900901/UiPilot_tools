# macOS 全机 Spotlight 隔离验收

这个工具用于 Apple Silicon、macOS 15.7.4 或更高版本。测试账户无需安装 Node、Rust 或 Xcode。日常使用的 UiPilot 可以保持现有版本。

## 运行

1. 直接登录已安排的本地**标准测试账户**。短名称为 `uipilot-qa` 或 `uipilot-qa-<小写字母或数字>`，主目录须属于该账户。使用专门存放合成数据的账户，以便独立观察 Spotlight 和系统权限。
2. 将交付的 ZIP 复制到该账户本地的测试目录（例如 `~/QA`），核对交付记录中的 SHA-256，解压并保留目录结构。
3. 双击 **run-spotlight-qa.command**。脚本会在 `/Users/Shared` 中创建一个由测试账户独占的临时目录，在两个子目录各放一张同名 PNG。它等待 Spotlight 自行收录，保留系统索引设置。
4. 记录终端显示的各阶段 PASS 或第一条失败消息。正常结束后工具会清理自身创建的样例。强制终止时可能保留本轮的私有测试目录。若系统拦截内部测试包，记录该提示，保留系统安全设置。

## 结果解释

- 两个目录对照都命中，说明同名样例均已收录；若缺少对照，工具会退出并跳过全机查询。
- 系统查询须命中允许目录的那一张，文件身份和宿主返回结果都须一致。对照目录用于检验过滤。测试程序以随机样例标识发起一次系统索引查询，只输出阶段及计数。
- 在同一进程撤回宿主核准的目录后，旧目标不得提交；再次核验也不能恢复该旧目标。此项使用模拟打开动作，Finder 不会启动。

真实系统隐私权限需用目标 UiPilot 安装包另验。分别记录允许访问、明确拒绝、撤权后的首次搜索，以及旧结果能否执行。如系统要求退出应用，记录实际进程是否重启，将同进程旧结果的结论单列。不要将测试工具的独立签名或共享目录样例的结果计作 UiPilot 的系统授权。
