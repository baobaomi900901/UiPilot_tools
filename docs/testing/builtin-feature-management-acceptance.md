# 内置功能管理验收记录

日期：2026-10-30。分支：`codex/builtin-screenshot`。设计合同：[设置插件列表中的内置功能管理](../superpowers/specs/2026-10-29-builtin-feature-management-design.md)。

## 实现范围

“设置 → 插件”的公共插件列表顶部固定显示截图、快捷链接、网页搜索三项，提供详情和启用开关，没有卸载或删除入口。三项由宿主专用接口管理，不作为公共插件包。旧设置默认全部启用，停用状态保存在现有设置文件中；启用状态变更后刷新当前启动器搜索，返回时保留输入。截图仍使用独立 `rust_uia` 编译物，本次没有修改 `rust_uia` 源码。

停用会阻止新的搜索结果和命令执行，已有结果的最终动作也会再次检查状态。截图快捷键注销但保留组合键；快捷链接数据、搜索引擎配置、收藏、已经进入的截图编辑会话及独立贴图保留。截图不发送系统通知或消息中心记录。

## 开发版人工验收

运行 `python D:\code\.tools\dev-uipilot.py --root D:\code\UiPilot_tools --rust-uia D:\code\rust_uia`，等待新一轮“主程序已就绪”后：

1. 打开“设置 → 插件”。确认三项内置功能固定在公共插件上方；搜索 `/screenshot`、`/quicklinks`、`/web-search` 或中文说明时过滤正确。逐项打开详情，检查命令、说明、版本、示例；用返回按钮和 Esc 返回。三项均没有卸载/删除按钮，原公共插件详情和删除入口仍存在。
2. 关闭截图。输入 `/screenshot`，尝试旧搜索结果和原截图快捷键，均不能启动新截图；已有贴图继续可操作。重新启用后，原快捷键和截图保存目录仍在，截图可重新启动。整个过程无截图消息推送。
3. 关闭快捷链接。`/quicklinks` 与已保存的自定义链接命令都不能打开或写入；重新启用后，原链接模板和图标仍在且可用。
4. 关闭网页搜索。输入 `/web-search` 和普通搜索词，均不出现网页搜索入口；重新启用后，原默认搜索引擎仍在。
5. 保持其中一项关闭，退出并重启主程序，确认开关状态仍为关闭；重新启用后恢复功能。检查深浅主题、开关快速连点，以及从带查询的启动器进入设置再返回时输入仍保留。

受控测试不代替真实全局快捷键冲突、托盘和多屏截图验收。393px 窄预览视口下，原公共插件标题与导入按钮会拥挤；桌面设置窗口的正常宽度仍需实机检查。
