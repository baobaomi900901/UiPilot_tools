# Screenshot toolbar icons

Canonical Lucide `x`, `pin`, `save`, and `copy` paths from `lucide-react` 1.21.0,
licensed under the included ISC LICENSE. Each `.alpha` file is a 64 × 64,
row-major, antialiased 8-bit opacity mask. Native code tints the masks using
the host theme and embeds them at compile time.

Regenerate from the installed package with `node generate.cjs` in this folder.
If `sharp` is outside the normal module path, pass its absolute module directory
as the first argument. Neither sharp nor Node is needed by the built app.
